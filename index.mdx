kkRPC lets two endpoints call each other through type-safe proxy objects. Expose an API on one side, wrap a transport on the other, and call remote functions just like local code — across Web Workers, iframes, stdio pipes, WebSockets, Electron, Tauri, Chrome extensions, or message brokers like Kafka and RabbitMQ.

## Why kkRPC?

kkRPC is designed for cross-runtime systems where the hard part is not just an HTTP API. It handles browser-to-worker, renderer-to-main-process, app-to-plugin-host, web-server-to-child-process, and service-to-message-broker communication with the same consistent API.

## Quick Example

```typescript
import { expose, wrap } from "kkrpc"
import { webSocketTransport, webSocketClientTransport } from "kkrpc/ws"

// Server: expose an API
const api = {
  async greet(name: string) {
    return `Hello, ${name}!`
  },
  math: {
    add(a: number, b: number) { return a + b }
  }
}
export type API = typeof api

expose(api, webSocketTransport(socket))

// Client: call it like local code
const remote = wrap<API>(webSocketClientTransport({ url: "ws://localhost:3000" }))
console.log(await remote.greet("World"))   // "Hello, World!"
console.log(await remote.math.add(1, 2))   // 3
```
